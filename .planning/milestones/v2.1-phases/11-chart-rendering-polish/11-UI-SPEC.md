Exceptions: none. Chart-specific layout contract (locked, pre-existing — must not change):

- Chart block: `relative min-h-[400px] w-full`; canvas container `min-h-[400px] w-full`.
- Stale badge: `absolute top-2 right-2` (8px offsets). Closed ribbon: `absolute inset-x-0 top-2`.
- Forming row: `px-1 py-2` (4px horizontal, 8px vertical).
- **Resize contract:** after any size change the canvas must exactly refill `div[data-slot="nq-chart"]`
  content box — no letterbox gap, no overflow, no stretch distortion, no clipped price axis. The
  observed element is the chart container itself (D-01), so panel/sidebar changes redraw too.

terminal tokens + `nq-chart.tsx` `readVar` fallbacks (pre-populated, not re-asked).

**Render-quality color rules (this phase's contract):**

- HiDPI fix must not shift any color value — crispness comes from backing-store resolution, never
  from re-tinting. Zone fills resolve `--terminal-premium-fill` / `--terminal-discount-fill` at draw
  time; stale desaturation stays `opacityScale = 0.5` over the 8% tokens (yields 4%), unchanged.
- Resize must not alter geometry colors: no flicker (no frame where fills/markers drop to
  transparent), no dropped overlays — Asia lines, Judas/SMT markers, zone fills persist exactly as
  before through every resize frame (D-04).

**Interaction contract (binding on implementation, all from 11-CONTEXT.md discretion + code context):**

1. Observe the chart container (`div[data-slot="nq-chart"]`), not just `window` — D-01.
2. Track size live during drag; debounce/throttle choice is executor discretion but must not visibly
   lag or freeze — D-02.
3. Preserve visible time range on resize (no re-fit); refresh zone-fill geometry after size change
   (`updateBands()`); overlays follow the existing remove-then-create / plugin-refresh pattern — D-03/D-04.
4. Lazy/DOM-free module top preserved: no top-level `window`/`ResizeObserver` access; dynamic import
   pattern; observer/listener torn down in the mount-effect cleanup alongside `chart.remove()` and
   primitive detach; resize failures degrade silently (candles never block).
5. Proof: (a) human HiDPI visual check, (b) resize refill check with overlay persistence asserted via
   `data-slot` hooks (`asia-lines`, `judas-markers`, `smt-marker`, `stale-badge`, `closed-ribbon`,
   `forming-row`, `chart-empty`), (c) clean console during resize + DPR/zoom switch — D-05/D-06.
