## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing; terminal-shell `p-4`, `gap-3`→12px grid gaps use sm/md only |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: 44px minimum touch target for icon-only controls (refresh button, risk-% steppers) — accessibility exception, not a spacing token. 11px/12px type sizes pair with 8px/12px gaps inside thin panels (existing terminal-shell precedent).

## Typography

Existing terminal precedent (terminal-shell.tsx, report.tsx): mono uppercase micro-labels, `text-xs` body, `text-base` verbatim reasons, `text-xl` emphasis values. Locked to exactly 4 sizes and 2 weights.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 12px (`text-xs`) | 400 (regular) | 1.5 |
| Label | 11px (`text-[11px]`, uppercase, `tracking-[0.1em]` or `tracking-widest`) | 600 (semibold) | 1.2 |
| Heading | 16px (`text-base`) | 600 (semibold) | 1.2 |
| Display | 20px (`text-xl`) | 600 (semibold) | 1.2 |

Rules:
- All numeric copy (prices, R/R ratios, contract counts, ages) is `font-mono tabular-nums`.
- Panel titles: Label role (`text-[11px] font-semibold uppercase tracking-[0.1em]`) — matches every existing CardTitle in terminal-shell.
- Verbatim Azerbaijani reasons (§4 trigger reason, §5 levels, §6 flaw sentence, STAND ASIDE reason): Heading role, 16px semibold, `text-base` — matches §3 `s3-liquidity-path` precedent.
- R/R ratio, entry/SL/TP prices, size in NQ contracts: Display role, 20px semibold mono — matches §2 bias + §3 conviction emphasis precedent.
- Banner copy (PAPER banner, thin/stale banners): Label role, 11px mono `tracking-widest`.
- Only two weights exist in this phase: 400 and 600. No medium (500), no bold (700).

## Color

Dark-only terminal (tokens in `app/globals.css` `.dark` block). Light `:root` tokens are shadcn neutral defaults and are NOT used by the terminal — executor must render terminal surfaces from `--terminal-*` tokens only.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #0a0a0f (`--terminal-background`) | Terminal background, page surface |
| Secondary (30%) | #14141e (`--terminal-panel`) | Cards, panels, report blocks, ticket panel |
| Accent (10%) | #00d9ff (`--terminal-accent`) | See reserved-for list — nothing else |
| Destructive | #D92636 (`--destructive`, light oklch(0.577 0.245 27.325); dark oklch(0.704 0.191 22.216)) | Destructive actions only — NO destructive action exists in this phase, so this token MUST NOT render anywhere in Phase 17 UI |

Accent reserved for: live status dot (`data-slot="live-dot"`), `yüksək inam` conviction tier text, chart 'T' trigger pin marker, chart entry/SL/TP price lines (EXECUTE only, reusing EQ/DOL create/remove lifecycle).

Semantic direction colors (NOT accent, NOT interchangeable with accent):
- Long / bullish / discount-fill: #00ff88 (`--terminal-up`, fills at 8% / 4% stale)
- Short / bearish / premium-fill: #ff00ff (`--terminal-down`, fills at 8% / 4% stale)
- Muted / stale overlays: gray (`MUTED_GRAY` in nq-chart; `text-muted-foreground` oklch(0.708 0 0) in dark)

State treatments (locked precedents, do not restyle):
- Unavailable: `pointer-events-none relative opacity-45` + absolute top-right `UNAVAILABLE` chip (11px semibold uppercase). The `UNAVAILABLE` chip copy is locked English — never translated.
- Degraded STALE/THIN: `opacity-45` + visible `STALE`/`THIN` provenance tag naming the failed leg (D-05). Numbers stay visible but dimmed; never full-strength ticket on stale/thin inputs.
- INVALIDATED (Phase 16 lock): neutral styling — no red/green direction tone, reason carries the verdict.
- Chart canvas: #0e0e12 (`--terminal-canvas`).

## Copywriting Contract

All verdict/reason prose is verbatim Azerbaijani from pure selectors, test-pinned with `toBe` (trigger D-09 / flaw D-10 precedent). Banned words — Filled, Position, Submit Order, placeOrder (identifiers or copy) — appear NOWHERE, enforced by the banned-word grep test (TICK-03).

| Element | Copy |
|---------|------|
| Primary CTA | KAĞIZ QEYD — EXECUTE-side only; logs intent as paper note, never submits anything |
| Secondary CTA | İMTİNA — STAND ASIDE-side; dismisses the paper note without logging |
| Empty state heading | Məlumat yoxdur |
| Empty state body | Məlumat yoxdur + next step: «Hələlik şam məlumatı əlçatan deyil. Yenilə düyməsini sıxın və ya 60 saniyə gözləyin.» with Yenilə button (chart-empty precedent) |
| Error state | Canlı məlumat əlçatan deyil — son keş göstərilir. Yenilə sıxın; problem davam edərsə terminal avtomatik yenidən cəhd edəcək. (locked POLL_FAILURE_COPY; toasts never surface raw upstream text; one coalesced toast per error value) |
| Destructive confirmation | None — no destructive actions exist in this phase; no confirmation dialog is built |
| PAPER banner | KAĞIZ / PAPER — persistent non-dismissible strip at terminal top (`data-slot="paper-banner"`, `role="status"`); visible even when the ticket panel is scrolled away |
| §5 title | PAPER prefix locked: §5 renders as «5. PAPER — INSTITUTIONAL ORDER TICKET» (D-06) |
| STAND ASIDE reason | Verbatim failing reason naming the gate (QUIET / ARMED / INVALIDATED / R-R fail); R/R fail MUST name the computed ratio, e.g. «R/R 1:1.8 — EXECUTE blocked» (D-03/D-04) |
| Degraded tag | STALE / THIN tag naming the failed leg, e.g. «STALE — 15M»; dimmed numbers stay visible (D-05) |
| Risk input | Risk % input, default 1%; size unit NQ contracts; label «Risk %»; degenerate inputs (zero stop distance, missing levels) refuse with verbatim reason, never compute |
| Chart trigger pin | Single 'T' glyph marker on the FIRE bar (J/S marker precedent; J first, then S, then T per UI-06 ordering) |
| Report §4 | Verbatim trigger reason (`selectTrigger` prose): «4. "WHY NOW?" EXECUTION PROTOCOL (5M/1M)» block, live |
| Report §6 | Falsifiable fatal-flaw sentence + challenge question from fixed bank, verbatim (Phase 16 lock carried forward) |
