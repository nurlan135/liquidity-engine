## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, inline badge padding (`2px 8px` badge uses 8px horizontal / 4px-class vertical rhythm) |
| sm | 8px | Compact row internals, badge padding, section-title bottom margin is 12px — see md |
| md | 16px | Default element spacing; app outer padding; section-title bottom margin 12px uses `12px` — exception-free: use 12px only as `12px` literal? No — see Exceptions |
| lg | 24px | Section padding inside panels (panel padding is 12px per reference; lg reserved for report-section separation) |
| xl | 32px | Layout gaps between stacked blocks inside a panel |
| 2xl | 48px | Major section breaks (report section separators) |
| 3xl | 64px | Page-level spacing (not used inside terminal; reserved) |

Exceptions: panel padding `12px`, grid gap `12px`, card radius `12px`, row vertical padding `8px`, badge padding `2px 8px`, section-title size/margin from reference (`11px` title, `12px` bottom margin, header padding `12px 16px`) — all match `reference/design.html` pixel values and are grandfathered as the layout contract. Chart block min-height `400px` (multiple of 4, per reference). Icon-only touch targets minimum `44px` where icon buttons are used (refresh button).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 12px | regular (400) | 1.5 |
| Label | 11px | semibold (600) | 1.2 |
| Heading | 16px | semibold (600) | 1.2 |
| Display | 20px | semibold (600) | 1.2 |

Rules:

- Exactly 4 sizes (11 / 12 / 16 / 20) and 2 weights (400 / 600) — no others anywhere in this phase.
- **Label** (11px / 600 / uppercase, `letter-spacing: 0.1em`, muted color) is for panel section titles (`SENTIMENT`, `CHART — NQ=F D1`, report section headers) and badge text (10px is NOT allowed — badges use 11px Label).
- **Body** (12px / 400 / 1.5) is for all rows, report prose, interpretation text, rationale strings.
- **Heading** (16px / 600 / 1.2) is for the institutional report title line (`# VALYUTA CÜTLÜYÜ … | HTF BIAS …` renders at 16px) and empty/error state headings.
- **Display** (20px / 600 / 1.2) is reserved for the header wordmark and the primary bias readout value (`BULLISH` / `BEARISH` / `COMPRESSION`) in report section 2.
- **Mono rule:** every numeric readout (prices, percentages, countdowns, timestamps, confidence, cache age) uses Geist Mono at the same size as its surrounding role. Code identifiers stay English; rendered copy is Azerbaijani (D-04).
- Header wordmark uses semibold 600 with `letter-spacing: 0.1em` (reference shows 800 — capped at 600 per the 2-weight rule).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0A0A0F` | App background, chart block background (`#0E0E12` grandfathered for the chart canvas only, per reference) |
| Secondary (30%) | `#14141E` | Panel/card surfaces, header strip, dialog/popover surfaces |
| Accent (10%) | `#00D9FF` (cyan) | See reserved-for list — and ONLY that list |
| Bullish / long-side | `#00FF88` (green) | Discount-zone shading tint, up-candles, LONG-allowed badge, bullish bias value |
| Bearish / short-side | `#FF00FF` (magenta) | Premium-zone shading tint, down-candles, SHORT-allowed badge, bearish bias value, struck-through blocked side |
| Muted text | `#71717A` | Labels, timestamps, secondary rows (from reference `--muted`) |
| Primary text | `#E4E4E7` | Body copy, prices (from reference `--text`) |
| Border | `rgba(255,255,255,0.08)` | Panel borders, row separators (from reference `--border`) |
| Destructive | existing `--destructive` token | Destructive actions only — none exist in this phase (see Copywriting Contract) |

Accent reserved for: (1) global status-strip LIVE dot + `LIVE` text, (2) EQ price-line on the chart, (3) DOL marker line/label, (4) manual refresh button (primary), (5) confidence value in header, (6) active-scenario indicator on the fixture switcher. Accent is NEVER used for body text, borders, or unavailable/dimmed surfaces.

Chart color rules (prescriptive):

- Up candle body/wick `#00FF88`, down candle body/wick `#FF00FF`, wicks same color as body.
- Premium zone fill: magenta at 8% opacity (`rgba(255,0,255,0.08)`); discount zone fill: green at 8% opacity (`rgba(0,255,136,0.08)`); EQ line: cyan dashed 1px; DOL marker: cyan solid 1px with mono price label on the axis.
- All four values are exposed as `app/globals.css` tokens (e.g. `--terminal-up`, `--terminal-down`, `--terminal-accent`, zone-fill tokens); components reference tokens, never literals.
- Stale state: chart canvas gets a `STALE` badge overlay (top-right of chart block) and zone fills desaturate to 4% opacity. Closed state: candles stay rendered, canvas gets a `MARKET CLOSED` overlay ribbon, no animation, no new candles ever synthesized (D-03).

UNAVAILABLE presentation (D-08): non-live modules (1/3/4) and report sections (1, 3–6) render dimmed in place — `opacity: 0.45`, no pointer events — with an explicit `UNAVAILABLE` marker chip (Label 11px, muted outline badge) pinned top-right of the dimmed block. Full 3-panel shape stays visible from day one.

Blocked side (D-09, UI-04): the non-actionable side row renders struck-through (`line-through`, magenta text) with a terse label — `BLOCKED — premium` or `BLOCKED — discount` — and no explanatory sentence.
