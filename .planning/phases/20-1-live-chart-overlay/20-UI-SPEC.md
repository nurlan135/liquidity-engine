## Typography

Existing terminal precedent (`report.tsx`, locked Phase 17 contract). Locked to exactly 4 sizes and 2 weights.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 12px (`text-xs`) | 400 (regular) | 1.5 |
| Label | 11px (`text-[11px]`, uppercase, `tracking-[0.1em]`) | 600 (semibold) | 1.2 |
| Heading | 16px (`text-base`) | 600 (semibold) | 1.2 |
| Display | 20px (`text-xl`) | 600 (semibold) | 1.2 |

Rules (source: `report.tsx` §3/§§4–6 branches, carried verbatim into §1):
- §1 section title (`h3`): Label role, 11px semibold uppercase `tracking-[0.1em]` — identical to every other `report-section` title.
- §1 sub-block label (`h4`, fixed Azerbaijani `Ağrı Həddi`): Label role, 11px semibold uppercase `tracking-[0.1em]` — mirrors `s3-liquidity-path` / `s3-smt-status` h4 idiom.
- §1 rank-1 sentence + empty/error lines: Heading role, 16px semibold `text-base` — mirrors §3 verbatim-reason prose and §§4–6 empty `Məlumat yoxdur` idiom.
- All numeric copy (zone bounds, ATR distance, prices): `font-mono tabular-nums`.
- Thin note + NY-style caveat lines: Body role, 12px `text-muted-foreground`.
- Only two weights exist in this phase: 400 and 600. No medium (500), no bold (700).

## Color

Dark-only terminal (tokens in `app/globals.css` `.dark` block). Light `:root` tokens are shadcn neutral defaults and are NOT used by the terminal — executor must render terminal surfaces from `--terminal-*` tokens only.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #0a0a0f (`--terminal-background`) | Terminal background, page surface |
| Secondary (30%) | #14141e (`--terminal-panel`) | Cards, panels, report blocks |
| Accent (10%) | #00d9ff (`--terminal-accent`) | See reserved-for list — nothing else |
| Destructive | oklch(0.704 0.191 22.216) (`--destructive`, dark) | Destructive actions only — NO destructive action exists in this phase, so this token MUST NOT render anywhere in Phase 20 UI |

Accent reserved for: live status dot (`data-slot="live-dot"`), `yüksək inam` conviction tier text, chart 'T' trigger pin marker, chart ticket entry/SL/TP price lines (EXECUTE only). Pool lines NEVER use accent — BSL uses `--terminal-up`, SSL uses `--terminal-down` (D-09).

Semantic direction colors (NOT accent, NOT interchangeable with accent):
- BSL pool lines: #00ff88 (`--terminal-up`); rank-1 pair full hex, rank-2 pair same hue at 50% alpha `rgba(0,255,136,0.5)` (D-10).
- SSL pool lines: #ff00ff (`--terminal-down`); rank-1 pair full hex, rank-2 pair same hue at 50% alpha `rgba(255,0,255,0.5)` (D-10).
- Swept ghost pairs: `MUTED_GRAY` #71717A (nq-chart precedent), both ranks — still visible for retest context, never removed (D-12).
- Stale/thin pool lines: `MUTED_GRAY` #71717A — uniform 0.5 dimming discipline, no stronger special dim for pools (D-13).
- Muted prose: `text-muted-foreground` (dark oklch(0.708 0 0)) — SWEPT sentence tone, thin note, empty/error secondary lines.

State treatments (locked precedents, do not restyle):
- Loading: `lastUpdatedISO === null` renders `h-3 animate-pulse` skeleton rows (`flex flex-col gap-3`) — identical to §3/§§4–6 branches (D-03).
- Unavailable branch REMOVED for §1 only: REPORT_SECTIONS index 1 flips to `live`; the `pointer-events-none relative opacity-45` + `UNAVAILABLE` chip branch no longer applies to §1 (D-22). All other sections keep it.
- Thin §1: sub-block wrapped in `opacity-45` + visible thin note (D-07) — matches zone/level 0.5-dimming discipline, never hidden like stale.
- Chart canvas: #0e0e12 (`--terminal-canvas`).
