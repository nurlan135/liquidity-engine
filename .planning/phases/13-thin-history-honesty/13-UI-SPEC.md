# Phase 13 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase scope (locked by 13-CONTEXT.md):** close the W-NEW-1 gap — `selectRange()` already
computes `thinHistory` and the regime path already degrades to `Sıxılma` below 34 candles, but
neither signal reaches the user's eyes. This phase surfaces them: a persistent banner strip above
the chart (reusing the `rollover-banner` pattern), uniform dimming of zones/levels on thin tiers,
full-strength markers. No new ICT math, no new overlays, no report-prose rework, no viewport
logic. Targets `components/dashboard/terminal-shell.tsx` and `components/charts/nq-chart.tsx`
(+ `zone-primitive.ts` dimming hook) only.

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing (banner `py-2`, badge offsets, empty-state `gap-2`) |
| md | 16px | Default element spacing |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: `px-3` (12px, multiple of 4) horizontal banner padding — locked pre-existing value from
the `rollover-banner` pattern, reused verbatim. `text-[11px]` badge/banner microcopy size is a
typography exception, not a spacing exception.

Banner-stack contract (binding, from D-01/D-02):

- Thin banner block: `rounded px-3 py-2` — byte-identical box to `rollover-banner`.
- When thin and rollover are both true, both strips render inside one wrapper
  `flex flex-col gap-2` (8px inter-banner gap), thin-history first, rollover second.
- Single-banner case renders the bare block with no wrapper (no stray gap).
- Chart block geometry unchanged from Phase 11: `relative min-h-[400px] w-full`; no viewport
  constraining, no canvas resize, no layout shift beyond the banner's own block height (D-07).

**Thin-dimming color rules (this phase's contract, from D-05/D-06/D-10):**

- Zone fills: `opacityScale = 0.5` whenever tier is not full — the exact stale precedent
  (`nq-chart.tsx` ~line 293), extended. Stale + thin never compound: the scale is 0.5 in every
  non-full case (single muted treatment, one branch).
- Level lines (`EQ`, DOL, `Q1`, `Q3`, `OTE-B`, `OTE-S`): color switches from accent to
  `MUTED_GRAY #71717A` whenever tier is not full — the same tone mechanism as `overlayStale`.
  Line widths, styles, and titles are unchanged; only the color value moves.
- Asia lines (`Asia-H`/`Asia-L`) and Judas/SMT markers stay full strength on every tier —

- Candles and wicks are never dimmed on any tier.
- Thin banner chrome: `text-muted-foreground` on panel, identical to `rollover-banner`. Tier
  distinction lives in copy, never in pixels — no per-tier banner tint (D-10).

## Thin-Tier Contract

Thresholds reuse the math constants — never UI-local literals (D-11). The UI imports the range
window (20) from the `computeRange` module and `MIN_CANDLES_FULL` (34) from `regime.ts`. Closed
candles = candles with `forming !== true`. Flag-plumbing shape (new `NqChart` prop vs derived
signal, selector form) is the planner's call; the tier truth table below is binding.

| Tier | Closed candles | Banner DOM | Chart rendering |
|------|---------------|------------|-----------------|
| range-thin | 1–19 (`thinHistory === true`, N < 20) | Tier-1 copy, `data-tier="range-thin"` | Dimmed: zones 0.5, level lines muted gray |
| regime-degraded | 20–33 (N < `MIN_CANDLES_FULL`) | Tier-2 copy, `data-tier="regime-degraded"` | Dimmed: identical single treatment (D-10) |
| full | 34+ | Absent — zero banner DOM, not hidden | Full strength, byte-identical to today |
| empty | 0 | Absent — `chart-empty` owns this state (D-04) | `Məlumat yoxdur` + Yenilə, unchanged |

Boundary pins: exactly 20 closed → regime-degraded; exactly 33 → regime-degraded; exactly
34 → full. `range-thin` holds if and only if `thinHistory` is true (same predicate, no drift).

Assertion hooks (binding): banner block carries `data-slot="thin-history-banner"`,
`data-tier="range-thin" | "regime-degraded"`, `data-closed-count="{N}"`; chart container
`div[data-slot="nq-chart"]` carries `data-thin-tier="full" | "range-thin" | "regime-degraded"`.

**Interaction contract (binding on implementation, all from 13-CONTEXT.md):**

1. Banner stack lives in the chart `CardContent` above the chart render branch: thin-history
   first, rollover second, inside `flex flex-col gap-2` only when both show (D-01/D-02).
2. Thin banner condition: `candles.length >= 1 && tier !== full`. Zero candles never show it (D-04).
3. Banner has `role="status"`, is never dismissible, persists on every thin render like the
   STALE badge (D-01/D-03).
4. No viewport constraining: candles render at natural width even if sparse; no custom viewport
   logic against Phase 11's view-preservation (D-07).
5. Lazy/DOM-free module top preserved; any thin-related observer/listener tears down in the
   mount-effect cleanup; thin-plumbing failure degrades silently — banner missing must never
   blank the chart (established `try/catch` + empty-fallback pattern).
6. Proof is automated + human: unit tests assert the thin flag reaches the chart, dimming applies,
   per-tier copy renders, and banners coexist; plus a human visual glance confirming honest look
   and a clean console (Phase 11 D-05/D-06 pattern, D-08).
