## Typography

Existing terminal precedent (`firing-log-panel.tsx`, `ticket-panel.tsx`, locked Phase 20 contract). Locked to exactly 4 sizes and 2 weights.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 12px (`text-xs`) | 400 (regular) | 1.5 |
| Label | 11px (`text-[11px]`, uppercase, `tracking-[0.1em]`) | 600 (semibold) | 1.2 |
| Heading | 16px (`text-base`) | 600 (semibold) | 1.2 |
| Display | 20px (`text-xl`) | 600 (semibold) | 1.2 |

Rules (source: firing-log + ticket panel precedent, carried verbatim):
- Panel titles (`Atəş Jurnalı`, sandbox block title): Label role, 11px semibold uppercase `tracking-[0.1em]`.
- Band verdict line + ticket buffer note + empty lines: Heading role, 16px semibold `text-base`.
- All numeric copy (fire-rate count, ATR buffer distance, slider values, prices): `font-mono tabular-nums`.
- Secondary lines (overflow `+N köhnə qeyd`, thin/stale notes, preview tag): Body role, 12px `text-muted-foreground`.
- Only two weights exist in this phase: 400 and 600. No medium (500), no bold (700).

## Color

Dark-only terminal (tokens in `app/globals.css` `.dark` block). Light `:root` tokens are shadcn neutral defaults and are NOT used by the terminal — executor must render terminal surfaces from `--terminal-*` tokens only.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #0a0a0f (`--terminal-background`) | Terminal background, page surface |
| Secondary (30%) | #14141e (`--terminal-panel`) | Cards, panels, calibration sandbox block |
| Accent (10%) | #00d9ff (`--terminal-accent`) | See reserved-for list — nothing else |
| Destructive | oklch(0.704 0.191 22.216) (`--destructive`, dark) | Band-BREAK verdict text + divergent proof-table rows ONLY (D-03/D-12 failure states); MUST NOT render anywhere when the band holds and verdicts match |

Accent reserved for: live status dot (`data-slot="live-dot"`), `yüksək inam` conviction tier text, chart 'T' trigger pin marker, chart ticket entry/SL/TP price lines (EXECUTE only), slider active-track fill + focused thumb ring (NEW this phase, POL-04). Pool lines NEVER use accent — BSL uses `--terminal-up`, SSL uses `--terminal-down` (Phase 20 D-09, unchanged).

Semantic colors (NOT accent, NOT interchangeable with accent):
- Band HOLD verdict: #00ff88 (`--terminal-up`) — Heading role, never accent.
- Band BREAK verdict: destructive token — Heading role, never accent.
- Proof-table identical rows: `text-muted-foreground`; divergent rows: destructive token (failure bar is exact verdict match, D-12).
- Buffered ticket note + buffer distances: `text-muted-foreground` Body/mono — matches thin-note precedent; chart SL/TP lines stay accent (EXECUTE only, unchanged z-order).
- Muted prose: `text-muted-foreground` (dark oklch(0.708 0 0)) — overflow line, preview tag, thin/stale notes.

State treatments (locked precedents, do not restyle):
- Loading: `lastUpdatedISO === null` renders `h-3 animate-pulse` skeleton rows (`flex flex-col gap-3`) — FiringLogPanel precedent.
- Sandbox preview (unapplied slider values): `opacity-45` + visible `BAXIŞ` tag — matches thin 0.5-dimming discipline, never hidden.
- Applied values: full opacity, tag clears via the same remove-then-create render cycle idiom.
- Degraded stale/thin: uniform 0.5 dimming (`opacity-45` + STALE/THIN tag), calibration reads degrade honestly and never throw on empty log.
- Chart canvas: #0e0e12 (`--terminal-canvas`); no new chart primitives in this phase (heatmap rejected, REQUIREMENTS.md Out of Scope).
