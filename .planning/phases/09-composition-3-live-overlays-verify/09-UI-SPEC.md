## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px (`text-base`) | 400 (regular) | 1.5 |
| Label | 12px (`text-xs`) | 400 (regular) | 1.5 |
| Heading | 11px (`text-[11px]`, uppercase, tracking 0.1em) | 600 (semibold) | 1.2 |
| Display | 20px (`text-xl`) | 600 (semibold) | 1.2 |

Rules (prescriptive, from existing `report.tsx` / `nq-chart.tsx` precedent):

- Exactly 4 sizes (11, 12, 16, 20) and exactly 2 weights (400 + 600). No other sizes or weights in this phase.
- Body (16px/400/1.5) is used for: sub-block reason lines, `Məlumat yoxdur` fallback, chart-empty heading.
- Label (12px/400/1.5) is used for: all §3 prose detail lines (`Mövqe:`, `Çatdırılma dövrü:`, AMD/SMT detail), regime/pre-news badge line, forming-row price, LONG/SHORT availability rows, dual-stamp session labels.
- Heading (11px/600/1.2, uppercase, `tracking-[0.1em]`) is used for: `3. LIQUIDITY SEQUENCING…` title, sub-block titles, `UNAVAILABLE` chip, `STALE` badge, `MARKET CLOSED` ribbon, `forming-chip`.
- Display (20px/600/1.2) is used for: the §3 conviction line value word only (e.g. `yüksək inam`) and the §2 bias precedent — never for prose.
- Mono (`font-mono`, tabular-nums) is used for: prices (`dol.price`, forming-row close), `STALE`/`MARKET CLOSED` badges, session time stamps (`London KZ 02:00–05:00 ET · 10:00–13:00 Baku`).
- Azerbaijani prose uses sentence case, never uppercase (badges/chips excepted).

Semantic candle/direction colors (not accent, not interchangeable):

| Token | Value | Usage |
|-------|-------|-------|

| Down / bearish | `#ff00ff` (`--terminal-down`) | Candle down, `BEARISH` bias text, premium fills `rgba(255,0,255,0.08)` (stale `0.04`) |

Accent reserved for: Asia-H price-line, Asia-L price-line, Judas confirmed-solid marker, SMT pin marker, §3 conviction-line value word. Never for: body prose, section titles, badges, zone fills, stale/closed chrome, LONG/SHORT rows.

Stale-dim treatment (D-08, locked):

- Zone fills: `zoneRef.current.opacityScale = status === 'stale' ? 0.5 : 1` (existing precedent, unchanged).
- Asia-H/Asia-L lines: persist on stale; color desaturated to muted gray (`#71717A`, the chart `textColor`) while stale leg owns them; restore accent on live. Never removed on stale.
- Judas/SMT markers: persist on stale; confirmed-solid accent desaturates to muted gray; candidate hollow-contrast likewise dulls; `STALE` badge (`data-slot="stale-badge"`) shows. Never cleared on stale.
- Chart never falls back to clean D1 silently: at least one of `data-overlay="stale"`, the `STALE` badge, or desaturated overlays is visible whenever any overlay leg is stale.

## §3 Layout Contract (normative for this phase)

`REPORT_SECTIONS` index 3 flips `unavailable` → `live`; title unchanged: `3. LIQUIDITY SEQUENCING & CROSS-MARKET SMT (1H/15M)` (`src/lib/report.ts:20`).

Structure inside the §3 `<section>`:

1. Heading row: `<h3>` title (Heading role) + conviction line directly under it (`data-slot="s3-conviction"`, Label 12px prose with Display 20px value word; value word in accent only for `yüksək inam`, muted for `standart`).
2. Three sub-blocks in fixed order, each its own `<div>` with a stable `data-slot`:
   - `data-slot="s3-liquidity-path"` — title `Likvidlik Yolu` + FVG prose or its reason verbatim.
   - `data-slot="s3-smt-status"` — title `SMT Statusu` + SMT prose or suppression reason verbatim.
   - `data-slot="s3-amd-timing"` — title `Sessiya AMD` + AMD reason verbatim + SMT tag suffix + dimmed NY line (`data-slot="s3-ny-line"`, `opacity-45`).
3. Each sub-block independently renders live content or its own reason (D-01); loading shows the existing three-bar `animate-pulse` skeleton; null-selector shows `Məlumat yoxdur`.
4. Unavailable detector families keep the locked `UNAVAILABLE` chip pattern (`absolute top-0 right-0`, Heading role) only if a whole family is missing — never as a §3-level banner over live siblings.

## Chart Overlay Contract (normative for this phase)

- Asia-H/Asia-L: two dashed accent price-lines (`lineWidth: 1`, `LineStyle.Dashed`, titles `Asia-H`/`Asia-L`) reusing the EQ/Q1/Q3 remove-then-create lifecycle verbatim (remove all line refs, null them, then create; guard-throw renders no lines, never blocks chart). Null-autoscale inherent to price lines — overlays never rescale candles (D-05).
- Judas markers via `createSeriesMarkers` (lightweight-charts v5 plugin API; `series.setMarkers` v4 form is banned): candidate = hollow-split (outline-contrast color + `circle` shape + text `J?`), confirmed = solid accent (`circle` shape + text `J`). Sweep side encodes position (`HIGH` sweep → `aboveBar`, `LOW` sweep → `belowBar`). Only confirmed (solid) counts toward conviction (D-12).
- SMT marker via `createSeriesMarkers`: single pin on the confirming D1 bar (`BULLISH` → `arrowUp` `belowBar`, `BEARISH` → `arrowDown` `aboveBar`, `NO-SIGNAL`/suppressed → no marker). Text `S`. Sweeper-leg detail stays in §3 prose (D-07).
- Marker `time` MUST equal the containing D1 candle `date` string (map Judas `sweepTime` epoch / SMT `windowStart`–`windowEnd` to the confirming bar date). `setMarkers([])` clears; refresh on data/selector change.
- ES stays off-chart: no ES series, no ES markers (locked scope).
- `data-slot` hooks (extend existing `data-slot="chart-block"` + `data-overlay={status}`): `data-slot="asia-lines"` (line pair presence), `data-slot="judas-markers"`, `data-slot="smt-marker"`, plus existing `stale-badge` / `closed-ribbon` / `forming-chip` / `chart-empty` / `nq-chart`. The DEPLOY-02 live-URL §3 render check probes `s3-liquidity-path`, `s3-smt-status`, `s3-amd-timing`, `s3-conviction` on the deployed URL.
